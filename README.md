# capstone-github

## Todo application
A simple local Todo app (add, view, edit, complete, delete; stored in SQLite) lives in [`todo-app/`](todo-app/README.md). It needs Node.js 24 or later and has no dependencies to install.

- Start: `cd todo-app` then `npm.cmd start` (or `node server.js`), and open http://127.0.0.1:3000. Stop with Ctrl+C.
- Test: `cd todo-app` then `node --test test/*.test.js` (or `npm.cmd test`).

See [`todo-app/README.md`](todo-app/README.md) for configuration, the API, and limitations. The welcome page (`index.html`) is separate and unchanged.
